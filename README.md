# MultiCast (マルチキャスト)

MultiCast は macOS 向けのソフトウェアオーディオミキサーアプリケーションです。
複数の入力デバイスからの音声をルーティング、ミキシングし、各種エフェクト（EQ、コンプレッサー、ノイズゲート等）をかけて出力することができます。

## 主な機能
- **最大 4入力 × 4出力** のオーディオルティング機能
- 各入力チャンネルごとの音量、ゲイン、パン調整
- **エフェクト機能**:
  - ノイズゲート
  - ローカットEQ
  - コンプレッサー
- **プリセット**:
  - `FPS`: ゲームプレイ向け（足音をクリアにしつつ、環境ノイズを低減）
  - `VC`: ボイスチャット向け
  - `Clean Mic`: マイククリーンアップ用
- **エラーロギング**: アプリ内の詳細ログやクラッシュ時のスタックトレースをファイルに保存し、アプリ内の「エラーログを表示」から閲覧・エクスポート可能

## 動作環境
- macOS 14.0 (Sonoma) 以降
- Apple Silicon / Intel Mac (Universal 2対応)

## ビルド方法
当プロジェクトは `xcodegen` を使用しています。
```bash
xcodegen generate
xcodebuild -project MultiCast.xcodeproj -scheme MultiCast build
```

## 更新履歴

### v1.1.0 (2026-10-06)
- **新機能**: エラーログ記録機能とアプリ内ログビューア (`LogViewerView`) を追加。
- **新機能**: クラッシュ時のシグナル（SIGSEGV, SIGABRT等）および例外をキャプチャし、スタックトレースをファイルに保存する機能を実装。
- **改善**: `FPS` プリセット使用時に発生していたバックグラウンドノイズを改善（コンプレッサーのメイクアップゲイン最適化、ノイズゲート閾値の調整）。
- **内部変更**: ログ出力機構を `os.log` 単体から、独自の `AppLogger` および `LogStore` へ移行。

### v1.0.0
- 初回基本実装（オーディオミキシング、エフェクト、プリセット機能、UI基盤）
